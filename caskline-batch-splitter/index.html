Privacy Policy for Caskline Batch Splitter

Last updated: August 22, 2026

This Privacy Policy explains how information is handled when you install, access, or use the Caskline Batch Splitter browser extension.

Caskline Batch Splitter is a practical browser tool designed to help users divide a total amount into balanced batches, compare capacity-based and evenly distributed allocation plans, review batch sizes, and export the resulting schedule as a CSV file.

The extension is intended for planning, allocation, scheduling, recordkeeping, workload breakdowns, and other personal or organizational calculations performed directly through its interface.

Privacy Summary

Caskline Batch Splitter does not require users to create an account or provide personal information in order to use its core batch calculation functionality.

Values entered into the extension are used to calculate batch allocations, compare distribution strategies, preview results, and generate CSV schedules requested by the user.

The extension is not designed to monitor unrelated browsing activity or build advertising profiles from user calculations.
